## Sobre a Pesquisa
A pesquisa utiliza a arquitetura **Transformer** e o modelo pré-treinado **BERTimbau** para classificar notícias em português como verdadeiras ou falsas, utilizando o dataset **Fake.Br Corpus**.

## Conteúdo do Notebook
- Instalação das bibliotecas (`transformers`, `pytorch`, `scikit-learn`).
- Carregamento e pré-processamento do dataset.
- Tokenização e treinamento do modelo.
- Avaliação de métricas (Acurácia, Precisão, etc).
